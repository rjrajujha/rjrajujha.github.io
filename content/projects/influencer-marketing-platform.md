## Problem

Growth teams needed one system to plan influencer campaigns, manage creator relationships, track deliverables, and report performance — replacing spreadsheets that did not scale with campaign volume.

## Solution

Next.js dashboards and creator-facing views over Node.js and FastAPI services. GraphQL and REST APIs share a MongoDB domain model. Role separation between admin, campaign manager, and read-only analytics. Campaign state machine with audit trail on transitions.

## Tech stack

Next.js · TypeScript · Node.js · FastAPI · GraphQL · REST · MongoDB · Docker

## Outcome

Replaced ad-hoc tooling for campaign operations and reporting. API-first design allows CRM and payment integrations without UI rewrites.

Internal production system — no public repository.
