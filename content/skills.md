## Backend Engineering

Node.js, TypeScript, and JavaScript for services, APIs, and automation. Express.js HTTP layers, versioned REST contracts, GraphQL for multi-client data fetching, WebSockets for real-time flows.

## Infrastructure

Docker for local parity and deployments. Linux server operations, Nginx reverse proxy and TLS termination, CI/CD pipelines for test and release.

## Databases

PostgreSQL for relational models and query tuning. MongoDB for document workloads. Redis for caching, queues, and rate limiting.

## Frontend

React and Next.js application layers with TypeScript. TailwindCSS for layout and responsive UI.

## Additional Experience

Python with FastAPI and Django for APIs and integration work when the stack or team standard calls for it.

## Engineering practice

API versioning, observability basics, DNS operations, and tests around critical paths. I favor maintainable service boundaries over clever abstractions.
